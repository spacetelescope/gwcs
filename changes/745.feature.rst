Expanded `gwcs.spectroscopy.WavelengthFromGratingEquation` to support FITS ``-GRA``/``-GRI`` grating coordinates by applying the grism correction terms to the input incident and refracted angle sines while preserving its original two-input grating-equation behavior, and added `gwcs.spectroscopy.RefractedAngleSineModel` to compute the pixel-to-refracted-angle-sine mapping used as the second input to that model.
